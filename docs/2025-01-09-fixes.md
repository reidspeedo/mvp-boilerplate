# Boilerplate Fixes - January 9, 2025

## Issues Fixed

### 1. Missing `package-lock.json`
**Problem**: Docker build failed because `npm ci` requires a lock file.
**Solution**: Users need to run `npm install` locally first to generate `package-lock.json`.

### 2. Missing `public` Directory
**Problem**: Dockerfile tried to copy `/app/public` which didn't exist, causing build failures.
**Solution**: Created `public/` directory with `.gitkeep` file. Next.js requires this directory for static assets.

### 3. Obsolete Docker Compose Version
**Problem**: `version: '3.8'` in docker-compose.yml is obsolete and generates warnings.
**Solution**: Removed the version attribute (modern Docker Compose doesn't require it).

### 4. Dockerfile Mismatch for Development
**Problem**: The production Dockerfile was being used with development docker-compose.yml (which has volumes mounted for hot-reload).
**Solution**: 
- Created `Dockerfile.dev` for development use (runs `npm run dev`)
- Updated `docker-compose.yml` to use `Dockerfile.dev` by default
- Kept production `Dockerfile` for production deployments

### 5. Dockerfile COPY Syntax Error
**Problem**: Attempted to use shell redirection in Dockerfile COPY command, which is invalid.
**Solution**: Fixed to use proper Dockerfile COPY syntax since `public/` directory now exists.

## Files Changed

1. **Created**: `public/.gitkeep` - Ensures public directory exists
2. **Created**: `Dockerfile.dev` - Development-focused Dockerfile
3. **Modified**: `Dockerfile` - Fixed COPY syntax for public directory
4. **Modified**: `docker-compose.yml` - Removed version, switched to Dockerfile.dev

## How to Use

### Development (with Docker)
```bash
docker-compose up
```

### Production Build
```bash
docker build -f Dockerfile -t mvp-boilerplate:prod .
```

## Notes

- The `public/` directory is now part of the repository
- Development uses `Dockerfile.dev` which runs the dev server
- Production uses `Dockerfile` which creates an optimized standalone build
- Both Dockerfiles now work correctly with the project structure
